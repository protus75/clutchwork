Write for a reader assessing whether a claim holds and where it applies. Use the supplied sources and preserve the distinction between observations, design proposals, and interpretations. In a derivation, trace each material claim to the canonical sections used.

## Question and claim

State the question, the answer the evidence supports, and the setting in which it was studied. If the source is a proposal, present the thesis as a hypothesis and identify what evidence would test it.

## Method and evidence

Explain what was observed, how cases were selected, and what counts as an outcome. For a quantitative result, identify the unit, numerator and denominator where applicable, time window or revision, and comparison baseline when supplied. Mark unavailable measurements explicitly. For Clutch run studies distinguish a ticket, an attempt, and a provider call. State which record establishes the outcome and which supplies diagnostic context.

## Findings and interpretation

Tie each finding to an identifiable local artifact, canonical section, or supplied observation. Compare like populations. If several isolated reviewers agree, report the count and whether the underlying document or run evidence verifies their finding. Attribute interpretation to the author. Preserve contrary cases and plausible competing explanations. For example, a retry count alone cannot establish why the first attempts failed.

## Limitations and implications

State what the evidence can support, the conditions that narrow the claim, and what observation would change the conclusion. Where the document recommends a decision, trace it to the findings. Mark unmeasured benefits and future evaluations as proposals. Give enough local source detail for a reader to inspect the reasoning.
