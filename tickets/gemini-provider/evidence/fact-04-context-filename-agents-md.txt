FINDING
context.fileName: "AGENTS.md" in the system settings file does load AGENTS.md from the working
directory (t19), but it ADDS to the default GEMINI.md instead of replacing it: with both files
present the model saw both codewords. Without the setting only GEMINI.md loads (t20). Source:
setGeminiMdFilename() in chunk-VLV2BYPM.js (~244555) unions the configured names with the current
list, which starts as ["GEMINI.md"]. So the plan's "Both set context.fileName to AGENTS.md"
selects AGENTS.md but cannot stop a host's GEMINI.md (or ~/.gemini/GEMINI.md) from also loading.
