During Check, the engine's meta fill wrote a `# purpose:` line for a new test file in llm-request-subject. That line quoted `request.ticket`, the identifier the test was scanning `tests/` to prove absent. The test's own header therefore matched its own absence scan, and the run lost one attempt. The note proposes one of two fixes: stop metafill from paraphrasing code identifiers into purpose lines, or make absence-scan tests skip `clutch:meta` headers by a convention written into the authoring guide.

Only one lost attempt is reported, and the cause is fragile test design more than an engine defect. A test that greps the whole `tests/` tree for a literal already has to keep that literal out of its own source, so a comment or header naming it is the same known hazard. Neither proposed fix is one bounded, measurable change. Telling the model not to quote identifiers is prose guidance whose effect cannot be observed reliably. A skip-meta-headers convention is a test-authoring style rule, and records 000431-000437 declined that class of guide addition when no repeated harm was shown. Open ticket meta-fill-drifted-no-model already cuts model rewrites of purpose lines to missing and empty_purpose files, which narrows how often this can happen. Open ticket lint-refuses-grep-verification sets the paved road for absence checks (assert absence inside the ticket's own unit test) and covers a different trap, a grep Verification exit code. Reopen if a second run loses an attempt because a metafill-written purpose line matched a test's absence scan, with the run and the scanned pattern named. At that point a scoped fix becomes justified, such as a shared absence-scan helper that ignores `clutch:meta` blocks, with a unit test.

- The message cites one incident: llm-request-subject lost 1 attempt when its purpose line contained `request.ticket` and the test's absence scan over `tests/` matched it.
- Open ticket meta-fill-drifted-no-model limits model-written purpose lines to `missing` and `empty_purpose` files, which shrinks the surface for this collision.
- Open ticket lint-refuses-grep-verification fixes a different absence-check trap (rg/grep exit 1) and points authors to in-test absence assertions; it does not cover header self-matches.
- Declined records 000431-000437 and 000609 turned down host-authoring guide additions that showed no recurring harm.
